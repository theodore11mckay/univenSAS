# UNIVEN Accommodation Management System

Production-ready Flask starter application for a UNIVEN accommodation workflow.

## Features
- Public accommodation directory with 12 seeded listings
- Listing image carousel with local fallback paths
- Accommodation details modal
- UNIVEN campus area map section
- Student registration and login
- POPIA disclosure
- Application workflow with funding source, academic year and degree code
- Document upload UI and secure filename handling
- Application status tracker and room assignment
- Maintenance tickets and status workflow
- Student/admin messaging
- Admin/landlord applicant inspection, approval/rejection and room assignment
- Broadcast messaging
- SQLite database by default

## Requirements
- Python 3.11+
- pip

## Install

Windows:
```powershell
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
python run.py
```

macOS/Linux:
```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python run.py
```

Open http://127.0.0.1:5000

## Image setup
Place local images in:
`app/static/img/`

Expected listing paths:
- `1room1.jpg` through `1room5.jpg`
- ...
- `12room1.jpg` through `12room5.jpg`

If an image is missing, the UI falls back to a neutral local SVG placeholder generated by the frontend.

## Production checklist
- Set a strong `SECRET_KEY` environment variable.
- Replace the demo admin PIN with a securely hashed credential workflow.
- Put Flask behind a production WSGI server such as Gunicorn/waitress.
- Use PostgreSQL/MySQL rather than SQLite for multi-user production deployments.
- Configure HTTPS and secure cookies.
- Configure an object store for uploaded documents.
- Add antivirus scanning and file-content validation for uploads.
- Add rate limiting, audit logs, CSRF protection on every state-changing form, and role-based authorization review.
- Replace the map placeholder with an approved UNIVEN map/embed and verify the exact official portal URLs.
- Obtain institutional approval for POPIA notices, retention periods and access controls.
